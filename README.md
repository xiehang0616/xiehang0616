## 🎯 我能带来什么

- **需求分析与体验设计：** 拆解用户任务，梳理交互流程、页面状态与异常路径，形成原型、PRD 和验收标准。
- **AIGC 应用与 Prompt 设计：** 判断 AI 的适用环节，设计提示词、结构化输出与人工确认机制。
- **RAG 与语义检索：** 设计知识问答与 Embedding 检索方案，关注相关性、回答依据和知识边界。
- **模型选型与效果评测：** 综合能力、时延、成本与稳定性选择模型，通过评测集和 Bad Case 分析推动迭代。
- **Agent Skills 与方法沉淀：** 将产品分析、评测流程和实践经验整理成可复用的 Skill、模板与报告。
